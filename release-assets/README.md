# 앱인토스 출시 이미지 준비

이 폴더에는 앱인토스 콘솔에 제출할 최종 이미지 또는 그 원본을 정리합니다. 규격은 제출 직전에 [미니앱 등록 가이드](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace.html)와 [UI/UX 가이드](https://developers-apps-in-toss.toss.im/design/consumer-ux-guide.html)에서 다시 확인하세요.

## 공식 이미지 규격

| 용도 | 규격 | 형식 | 제출 |
| --- | --- | --- | --- |
| 앱 로고 | 600×600px | PNG | 필수 |
| 게임 썸네일 | 1932×828px | PNG | 필수 |
| 세로 스크린샷 | 636×1048px, 최소 3장 | PNG | 선택 |
| 가로 스크린샷 | 1504×741px, 최소 1장 | PNG | 선택 |
| 공유용 OG 이미지 | 1200×600px | 고화질 이미지 | 공유 마케팅 사용 시 선택 |

세로 또는 가로 스크린샷을 제출할 때는 실제 출시 방향에 맞는 한 종류를 우선 준비합니다.

## 앱 로고 체크리스트

- [ ] 캔버스가 정확히 600×600px입니다.
- [ ] 모서리를 둥글게 자르지 않은 정사각형입니다.
- [ ] 배경색이 있으며 투명 영역이 없습니다.
- [ ] 작은 크기로 축소해도 게임을 식별할 수 있습니다.
- [ ] 라이트 모드와 다크 모드에서 모두 자연스럽게 보입니다.
- [ ] 다른 앱과 혼동되지 않습니다.
- [ ] 토스가 제공한 아이콘·이미지·이모지를 사용하거나 2차 가공하지 않았습니다.
- [ ] 직접 제작했거나 상업적 사용 권리를 확보한 요소만 사용했습니다.
- [ ] SDK 3.x 기준으로 최종 로고를 앱인토스 콘솔에 업로드합니다.

권장 파일명: `bounc-lab-logo-600.png`

## 게임 썸네일 체크리스트

- [ ] 캔버스가 정확히 1932×828px입니다.
- [ ] 실제 게임의 핵심 플레이 장면이 보입니다.
- [ ] 작은 원본을 억지로 확대하지 않은 선명한 이미지입니다.
- [ ] 비율을 맞추려고 빈 공간을 단색이나 블러로 채우지 않았습니다.
- [ ] 게임 로고 또는 짧은 문구 외에 텍스트를 과도하게 넣지 않았습니다.
- [ ] 비속어, 정치적 표현, 선정적·폭력적·불쾌한 요소가 없습니다.
- [ ] 다른 게임의 캐릭터·로고·배경 등 권리 문제가 있는 자료가 없습니다.
- [ ] 실제 출시 버전과 다른 기능이나 보상을 암시하지 않습니다.

권장 파일명: `bounc-lab-thumbnail-1932x828.png`

## 스크린샷 캡처 체크리스트

다음 장면을 후보로 캡처합니다.

- [ ] 대표 스테이지의 실제 플레이 화면
- [ ] 모바일 조작 UI와 목표가 명확히 보이는 화면
- [ ] 맵 에디터에서 맵을 만드는 화면
- [ ] 검증 플레이를 마치고 게시할 수 있게 된 화면
- [ ] 온라인 맵 목록과 다른 사용자의 맵을 플레이하는 화면

모든 캡처에서 다음을 확인합니다.

- [ ] 로컬 주소, 개발자 도구, 디버그 로그, 테스트 배지와 오류 문구가 없습니다.
- [ ] 이메일, 토큰, IP 주소, QR 코드 등 개인정보나 비밀값이 없습니다.
- [ ] 토스 닫기 버튼과 Safe Area를 침범하는 UI가 없습니다.
- [ ] 페이지 스크롤바, 잘린 버튼, 레터박스 또는 빈 웹뷰 영역이 없습니다.
- [ ] 글자가 잘리지 않고 한국어 표기가 정상입니다.
- [ ] 실제 출시 데이터와 동일한 기능만 보여줍니다.
- [ ] 원본 캡처는 편집 전 별도로 보관합니다. 등급분류 제출용 플레이 화면은 임의로 합성하거나 과도하게 편집하지 않습니다.

## 파일 관리

- 콘솔 제출용 PNG와 편집 가능한 원본을 구분해 보관합니다.
- 원본 이미지의 제작자, 라이선스와 출처를 기록합니다.
- API 키, 콘솔 토큰, 인증서, 개인정보가 포함된 파일은 이 폴더에 넣지 않습니다.
- 최종 제출 전에 파일을 실제 픽셀 크기와 PNG 형식으로 다시 검사합니다.
