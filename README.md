# BOUNC LAB

펭귄 바운스볼 100개 스테이지에 **맵 제작 → 직접 클리어 검증 → 온라인 게시 → 링크 공유** 흐름을 더한 웹 게임입니다.

## 실행

Node.js 20 이상만 있으면 별도 패키지 설치 없이 실행됩니다.

```powershell
npm start
```

브라우저에서 `http://localhost:8787`을 여세요.

## 주요 기능

- 기존 공식 100개 스테이지와 자동 바운드 물리 보존
- 두 곡이 순서대로 반복되는 펭귄 바운스 BGM과 합성 효과음
- PC 키보드와 모바일 스틱/좌우 터치 조작
- 세로·가로 화면을 채우며 펭귄을 따라가는 모바일 카메라
- 20×15 온라인 맵 에디터와 자동 임시저장
- 현재 맵 버전의 좌우 입력을 서버가 120Hz 결정적 물리 엔진으로 재실행해 실제 클리어된 경우에만 게시 버튼 활성화
- 맵을 한 칸이라도 바꾸면 클리어 인증 즉시 무효화
- 맵 해시·작성자 토큰·1회용 서명 티켓을 확인한 뒤 서버 게시
- 최신/인기/클리어순 온라인 갤러리, 검색, 플레이·클리어 수
- `?map=<map-id>` 공유 링크로 게시된 불변 버전 바로 열기
- 데스크톱·모바일 반응형 단일 화면 UI

## 화면 흐름

1. 홈에서 **맵 만들기**를 엽니다.
2. 타일, 시작점, 오른쪽 출구를 배치합니다. 편집 내용은 자동 저장됩니다.
3. 제목과 제작자 이름을 입력하고 **검증 플레이**를 누릅니다.
4. 그 버전을 직접 클리어하면 입력 리플레이를 서버가 동일한 120Hz 물리로 검증하고, 성공 시 **온라인에 게시하기**로 버튼이 바뀝니다.
5. 게시 후 링크를 공유하거나 온라인 맵 목록에서 바로 플레이합니다.

## 운영 설정

개발 중에는 임시 서명 키로도 실행되지만, 인터넷에 배포할 때는 반드시 고정된 비밀값을 설정하세요.

```powershell
$env:PUBLISH_SECRET = '32바이트 이상의 충분히 긴 무작위 문자열'
$env:PORT = '8787'
npm start
```

게시된 맵은 기본적으로 `data/maps.json`에 원자적으로 저장됩니다. 실제 운영 서버에서는 이 경로가 유지되는 디스크/볼륨에 있어야 합니다. API와 보안 규칙은 [BACKEND.md](./BACKEND.md)에 정리되어 있습니다.

## 앱인토스 빌드

SDK 3 개발용 번들은 다음 명령으로 만들 수 있습니다. 결과물은 프로젝트 루트의 `bounc-lab.ait`이며, `bounc-lab`은 콘솔 등록 전 임시 `appName`입니다.

```powershell
npm ci
npm run build:toss:dev
```

로컬 Toss 화면에서 온라인 맵까지 확인하려면 API 서버(`npm start`)를 함께 실행한 뒤 `npm run dev:toss`를 사용하세요. Vite가 `/api` 요청을 기본 `http://127.0.0.1:8787`로 전달합니다.

실제 제출용 빌드는 확정된 `TOSS_APP_NAME`과 공개 HTTPS `VITE_API_BASE_URL`이 없으면 중단됩니다. 콘솔 정보, 이미지 규격, 등급분류, 외부 API 배포와 QR 실기기 검증은 [TOSS_RELEASE.md](./TOSS_RELEASE.md)를 따르세요.

## 후속 접근성 과제

- 모든 오버레이를 공통 modal dialog로 전환하고 초점 이동·초점 가두기·원위치 복귀·Escape 닫기를 제공합니다.
- 맵 편집 캔버스에 키보드 셀 이동, 현재 좌표/타일 안내, Enter·Space 배치 기능을 제공합니다.
