개인정보처리방침

펭귄 바운스는 공식 스테이지 플레이와 이용자가 만든 온라인 맵의 검증·게시·공유·신고 기능을 제공합니다.

토스 미니앱 배포판에서만 Apps in Toss 통합 광고(Toss Ads/Google AdMob)를 사용합니다. Google Play·ONEstore용 Android 앱과 일반 웹 배포판에는 광고 SDK가 포함되지 않습니다. 온라인 맵·신고 기능은 Cloudflare Workers와 D1을 사용하며, 이 기능을 사용하지 않으면 대부분의 게임 정보는 기기 안에만 저장됩니다.

1. 처리하는 정보

구분항목처리 방식
기기 내 게임 정보스테이지 진행, 점수, 음향·조작 설정, 직접 만든 맵 초안, 최근 맵 제목·제작자명, 무작위 익명 작성자 토큰, 커뮤니티 약관 동의 버전, 내 게시 맵 ID, 내가 숨긴 맵·제작자 ID앱 WebView의 로컬 저장소에 보관됩니다.
토스 미니앱 배포판에서 전달될 수 있는 정보토스의 익명 이용자 식별 해시, 프로필 닉네임토스 미니앱에서만 해당합니다. 식별 해시는 익명 작성자 토큰을 만드는 데 사용하고, 닉네임은 제작자 표시명 입력을 편하게 채우는 데 사용합니다. 앱 기기 내 저장소에 보관될 수 있습니다.
토스 미니앱 광고 정보광고 또는 기기 식별정보(기기·운영체제·토스의 설정과 동의에 따라 제공되는 경우), IP 주소, 앱·기기·운영체제 정보, 광고 요청·노출·클릭 정보, 오류·성능 등 진단 정보토스 미니앱에서 광고를 요청하거나 표시할 때 Apps in Toss 통합 광고와 그 광고 제공자가 처리할 수 있습니다. 펭귄 바운스 운영 서버의 D1에는 개별 광고 요청·노출·클릭 기록이나 광고 식별정보를 별도로 저장하지 않습니다.
온라인 게시 정보맵 제목, 이용자가 입력한 제작자 표시명, 20×15 맵 구조·시작점·출구, 게시 시각, 플레이·클리어 횟수, 공개용 익명 제작자 IDCloudflare D1 데이터베이스에 저장되며 다른 이용자에게 공개됩니다. 작성자 토큰 원문과 비공개 소유권 해시는 공개 API로 제공하지 않습니다.
클리어 검증 및 소유권 정보맵 구조, 좌우 입력 리플레이, 플레이 시간·바운드 횟수, 작성자 토큰의 SHA-256 해시, 동의한 약관 버전직접 클리어한 맵만 게시하기 위해 입력 리플레이를 Cloudflare Worker에서 일시적으로 재생하며 리플레이 원문은 D1에 저장하지 않습니다. 맵 구조·검증 결과·소유권 해시·약관 버전은 게시와 본인 삭제 권한 확인을 위해 D1에 저장합니다.
신고 정보신고 대상 맵·제작자, 신고 사유와 이용자가 입력한 설명, 신고자 익명 식별값, 접수·처리 시각과 조치 결과커뮤니티 이용규칙 위반을 검토하고 콘텐츠를 숨기거나 삭제하기 위해 Cloudflare D1에 저장합니다.
접속 정보요청 IP 주소, 요청 제한용 SHA-256 식별값, 제한 창의 시작·만료 시각과 요청 횟수Cloudflare는 요청 전달·보안·인프라 운영 과정에서 IP 주소와 요청 메타데이터를 처리할 수 있습니다. 앱 Worker는 원 IP 주소를 D1에 저장하지 않습니다. SHA-256 식별값은 일반·쓰기 요청의 Workers Rate Limiting과 신고 요청의 D1 제한에만 사용합니다.

2. 이용 목적

  • 게임 진행과 이용자 설정 복원
  • 맵 초안 저장, 클리어 검증, 온라인 게시와 공유
  • 게시 맵 검색·정렬 및 플레이·클리어 통계 제공
  • 맵·제작자 신고, 기기 내 숨김, 본인 게시물 삭제와 운영자 조치
  • 부정 게시 방지, 약관 동의 확인, 서비스 안정성 유지와 요청 횟수 제한
  • 토스 미니앱에서 광고 제공, 노출 빈도 관리, 광고 성과 측정, 무효 트래픽·부정행위 방지, 광고비 정산과 오류 대응

3. 보관 기간

  • 기기 내 정보: 앱 데이터 삭제 또는 앱 제거 시까지
  • 검증 시도: 생성 후 2시간 동안 유효하며, 만료 뒤 정기 또는 수시 정리 작업 때 D1에서 삭제
  • 게시 티켓: 발급 후 20분 동안 유효하며 사용하거나 관련 검증 기록을 정리할 때까지
  • 요청 제한 상태: 일반·쓰기 요청의 해시 식별값과 횟수는 Workers Rate Limiting에서 1분 동안 임시 처리하며, 신고 요청의 해시 식별값과 횟수는 D1에서 1시간 동안 제한에 사용한 뒤 정기 또는 수시 정리 작업 때 삭제
  • 게시된 맵과 표시명·소유권 정보: 이용자가 직접 삭제하거나 삭제 요청이 처리되거나 서비스가 종료될 때까지
  • 신고 및 처리 기록: 신고 검토, 분쟁 대응과 커뮤니티 보호에 필요한 기간 또는 관련 맵 삭제 때까지
  • D1 복구 기록: 현재 사용하는 무료 요금제의 Time Travel 복구 지점에는 삭제·수정 전 데이터가 최대 7일간 남을 수 있으며 그 뒤 자동 만료
  • Cloudflare 인프라 메타데이터: 네트워크 보안, 장애 대응과 서비스 운영을 위해 Cloudflare의 서비스 설정과 정책에 따른 기간 동안 처리될 수 있음
  • 토스 미니앱 광고 정보: 펭귄 바운스 운영 서버에는 별도 저장하지 않으며, Apps in Toss 통합 광고와 광고 제공자의 서비스 설정·법적 의무·개인정보처리방침에 따른 기간 동안 처리될 수 있음

4. 공개, 처리위탁 및 국외 처리

온라인 게시 버튼을 누르면 맵 제목, 제작자 표시명, 맵 내용, 게시 시각, 이용 통계와 공개용 익명 제작자 ID가 누구나 조회할 수 있게 공개됩니다. 실명이나 연락처 등 공개를 원하지 않는 정보는 제작자명과 제목에 입력하지 마세요. 공유 기능을 사용하면 토스 또는 운영체제의 공유 화면으로 맵 링크와 제목이 전달될 수 있습니다.

토스 미니앱 배포판은 Apps in Toss 통합 광고(Toss Ads/Google AdMob)를 통해 전면 광고를 표시할 수 있습니다. 이 과정에서 광고 기능 제공자인 주식회사 비바리퍼블리카(Apps in Toss/Toss Ads)와 Google LLC(Google AdMob)가 광고 또는 기기 식별정보, IP 주소, 앱·기기·운영체제 정보, 광고 요청·노출·클릭 정보와 진단 정보를 처리할 수 있습니다. 처리 목적은 광고 제공, 노출 빈도 관리, 성과 측정, 무효 트래픽·부정행위 방지, 광고비 정산과 오류 대응입니다.

광고 관련 실제 처리 항목은 기기·운영체제·토스의 설정과 이용자 동의, 광고 요청 시점과 광고 제공자의 정책에 따라 달라질 수 있습니다. Apps in Toss와 Google의 글로벌 광고 인프라를 통해 대한민국 외 지역에서 정보가 처리될 수 있으며, 처리 위치와 보관 기간도 각 제공자의 서비스 구성과 개인정보처리방침에 따릅니다. 자세한 내용은 토스 개인정보처리방침과 Google 개인정보처리방침에서 확인할 수 있습니다.

Google Play·ONEstore용 Android 앱과 일반 웹 배포판에는 Apps in Toss 또는 Google AdMob 광고 SDK가 포함되지 않으며 광고를 표시하지 않습니다. 토스 미니앱 이외의 배포판에서는 광고 목적으로 위 광고 정보를 처리하지 않습니다.

서비스의 정적 파일 전송, API 실행, 데이터베이스 저장·복구, 네트워크 보안과 장애 대응을 위해 Cloudflare, Inc.의 Workers, Static Assets와 D1 서비스를 사용합니다.

Cloudflare의 글로벌 인프라 특성상 온라인 기능을 사용할 때 IP 주소와 요청 메타데이터, 온라인 게시·검증·소유권·신고·요청 제한 정보가 네트워크를 통해 자동 전송되어 대한민국 외 지역에서 처리될 수 있습니다. 실제 처리 위치와 인프라 로그 보관 기간은 이용자의 접속 위치, Cloudflare의 서비스 구성과 정책에 따라 달라질 수 있습니다. 국외 처리를 원하지 않으면 온라인 맵 조회·게시·공유·신고 기능을 사용하지 않을 수 있으며, 이 경우에도 기기 내 공식 스테이지는 이용할 수 있지만 온라인 기능은 제공되지 않습니다.

5. 삭제 및 이용자 권리

기기 내 정보는 운영체제의 앱 정보에서 저장공간·데이터를 삭제하거나 앱을 제거해 지울 수 있습니다. 현재 버전에서 게시했고 게시한 기기의 익명 작성자 토큰이 유지되는 맵은 온라인 맵에서 해당 맵을 선택하고 내 맵 삭제를 눌러 맵과 관련 신고 기록을 삭제할 수 있습니다.

기기 변경 또는 앱 데이터 삭제로 자동 소유권 확인이 어려운 경우 맵 ID, 맵 제목, 제작자 표시명과 요청 사유를 아래 이메일로 보내주세요. 비밀번호, 익명 작성자 토큰, 서명키는 보내지 마세요. 운영자는 필요한 확인을 거쳐 게시 맵과 관련 공개 정보를 삭제합니다.

6. 안전조치

  • 운영 API는 공개 HTTPS 연결만 사용합니다.
  • 작성자 토큰은 무작위로 생성하고 서버 게시 기록에는 원문을 저장하지 않습니다.
  • 요청 제한에는 IP 주소 원문 대신 SHA-256으로 변환한 식별값을 사용합니다.
  • 입력 크기·형식 검증, 게시·신고 요청 제한, 1회용 게시 티켓과 서버 측 클리어 재검증을 적용합니다.
  • 신고·기기 내 차단·본인 삭제 기능과 운영자 전용 숨김·삭제 조치를 제공합니다.

8. 방침 변경

수집 항목, 이용 목적, 외부 SDK 또는 운영 사업자가 바뀌면 시행 전에 이 페이지를 갱신하고 중요한 변경은 앱 또는 스토어 공지로 알립니다. 버전 1.3에서는 토스 미니앱 전용 Apps in Toss 통합 광고의 처리 항목·목적·제공자와 국외 처리 가능성, Android·일반 웹 배포판에는 광고 SDK가 없다는 점을 추가했습니다.
