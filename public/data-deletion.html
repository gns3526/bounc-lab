데이터 삭제 안내

앱: 펭귄 바운스
개발자·개인정보처리자: 김태훈

펭귄 바운스는 별도 서비스 계정을 만들도록 요구하지 않습니다. 기기 안의 게임 데이터와 이용자가 선택해 온라인에 게시한 맵 데이터는 아래 방법으로 삭제할 수 있습니다. 토스 미니앱의 광고 제거 구매는 토스·앱마켓 주문 이력과 연결되며 데이터 삭제와 환불은 서로 다른 절차입니다.

1. 온라인에 게시한 맵 삭제

  1. 맵을 게시했던 기기에서 펭귄 바운스를 실행합니다.
  2. 온라인 맵에서 본인이 게시한 맵을 선택합니다.
  3. 내 맵 삭제를 눌러 삭제를 확인합니다.

게시 당시 기기에 저장된 익명 소유권 정보가 확인되면 게시 맵, 공개 제작자 표시명, 맵 구조, 공개 통계와 해당 맵에 연결된 신고 기록이 삭제됩니다.

2. 이메일로 삭제 요청

기기를 바꾸었거나 앱 데이터를 지워 자동 소유권 확인이 어려우면 아래 정보를 hoon@jellysnow.com으로 보내 주세요.

  • 맵 ID
  • 맵 제목
  • 게시할 때 사용한 제작자 표시명
  • 삭제 요청 사유

보내지 마세요: 비밀번호, 익명 작성자 토큰, 서명키 또는 불필요한 개인정보. 운영자는 필요한 소유권 확인을 거쳐 게시 맵과 관련 공개 정보를 삭제합니다.

3. 기기에 저장된 데이터 삭제

Android의 설정 → 앱 → 펭귄 바운스 → 저장공간 → 데이터 삭제를 선택하거나 앱을 제거하면 스테이지 진행, 점수, 설정, 맵 초안과 기기 내 익명 소유권 정보가 삭제됩니다. 메뉴 이름은 Android 기기에 따라 조금 다를 수 있습니다.

토스 미니앱에서는 토스 앱 데이터 삭제 또는 토스 앱 제거 시 Toss Native Storage에 저장된 광고 제거 권한의 로컬 캐시가 함께 삭제될 수 있습니다. 이 경우 펭귄 바운스의 구매 복원을 실행하면 토스·앱마켓 주문 이력에서 완료된 광고 제거 주문을 다시 확인합니다.

4. 결제 데이터 삭제와 환불

데이터 삭제는 결제 취소나 환불 신청이 아닙니다. 광고 제거 결제를 환불하려면 Android에서는 토스 앱의 인앱결제 구매내역에서 환불받기를 선택하고, iOS에서는 Apple의 환불 절차를 이용해 주세요. 환불이 완료되면 광고 제거 권한이 해제되고 광고가 다시 표시됩니다.

주문 ID, SKU, 완료·환불 상태와 구매·환불 시각 같은 주문 기록은 펭귄 바운스의 Cloudflare D1에 저장하지 않습니다. 토스와 Google 또는 Apple은 결제·환불·분쟁 처리와 관계 법령 준수를 위해 각 정책과 관계 법령에 따른 기간 동안 주문 기록을 보관할 수 있습니다.

5. 삭제 뒤 남을 수 있는 정보

  • Cloudflare D1의 복구 지점에는 삭제 전 데이터가 최대 7일간 남은 뒤 자동 만료될 수 있습니다.
  • 법령 준수, 보안, 부정 이용 방지 또는 분쟁 대응에 꼭 필요한 기록은 해당 목적에 필요한 기간 동안만 별도로 보관될 수 있습니다.

6. 문의

구매 문의에는 주문 ID, 이용한 운영체제와 대략적인 결제 시각만 적어 주세요. 카드번호, 계좌번호, 비밀번호, 인증번호, 익명 작성자 토큰이나 서명키는 보내지 마세요.
